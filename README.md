# Amusement Park Management System

Dự án nhóm quản lý khu vui chơi: bán vé/POS, kiểm soát vé, kho, khách hàng và báo cáo.

## Công nghệ

C#, WinForms, DevExpress, SQL Server, LINQ to SQL; kiến trúc GUI/BUS/DAL.

## Chạy tại máy

Windows, Visual Studio, .NET Framework 4.8, SQL Server và DevExpress phù hợp với tham chiếu trong GUI.csproj. Mở DaiNam.sln, khôi phục NuGet và cấu hình kết nối SQL Server. Các ứng dụng web bổ sung dùng .NET 10. Các script SQL nằm trong mã nguồn; kiểm tra trước khi chạy trên cơ sở dữ liệu riêng.

Cấu hình mật khẩu được thay bằng giá trị mẫu. Thư mục build và thư viện đã biên dịch không được đưa vào repo. Đây là mã nguồn dự án học tập theo nhóm; mô tả chức năng không ngụ ý một thành viên thực hiện toàn bộ.
